🔬 Лабораторія ОВДП

Експеримент №3 · HTTPS + офлайн-сховище

Перевіряємо, чи може застосунок зберігати довідник і відкривати його після перезапуску без інтернету.

1. Збереження даних

Для першої перевірки використаємо 194 демонстраційні записи. Це не реальні дані НБУ.

2. Реальний довідник НБУ (додаткова перевірка)

Коли матимемо перевірену адресу JSON НБУ, її можна вставити сюди. Дані завантажуються лише за натисканням кнопки.

Доступність запиту залежить від дозволів CORS сервера НБУ. Тестові дані не замінюють офіційний довідник.

3. Результат

Готово до перевірки.

Важливо: для офлайн-відкриття самої сторінки після повного закриття браузера потрібен окремий механізм кешування (Service Worker / PWA). Цей тест перевіряє насамперед збереження даних у сховищі браузера.

Тестова сторінка не містить персональних фінансових даних. Збереження виконується локально у цьому браузері.
